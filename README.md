# 🌿 Carla Saporques | Psicologia Clínica

Landing page desenvolvida para apresentar os serviços de uma profissional de psicologia clínica, proporcionando aos visitantes uma experiência visual agradável, moderna e acolhedora.

O projeto tem como objetivo transmitir confiança, profissionalismo e tranquilidade, facilitando o acesso às informações sobre a profissional e seus atendimentos.

## ✨ Funcionalidades

- **Página inicial:** apresentação da profissional e proposta de atendimento.
- **Quem sou:** seção dedicada à apresentação e trajetória da psicóloga.
- **Horários:** informações sobre disponibilidade de atendimento.
- **Categorias:** apresentação das áreas de atuação.
- **Agendamento:** acesso facilitado para entrar em contato e agendar uma consulta.
- **Layout responsivo:** adaptação da interface para diferentes tamanhos de tela.

## 🎨 Design

A identidade visual foi desenvolvida com foco em uma experiência minimalista e acolhedora.

- Paleta de cores em tons de verde escuro e verde suave.
- Tipografia elegante e de fácil leitura.
- Elementos visuais minimalistas.
- Organização das informações com foco na experiência do usuário (UX).
